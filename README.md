# ZV-E10 Viewer

Лёгкая программа для macOS: живое видео с камеры Sony ZV-E10 по USB и управление её настройками с компьютера. Замена Imaging Edge Desktop (Remote) без лишнего: открыл — сразу картинка, основные настройки в один клик.

![Главный экран](docs/screenshots/1-main.png)

## Что умеет

- **Сама находит камеру** по USB и показывает живое видео на всё окно. Отключили кабель — ждёт и подключается снова.
- **Строка значений внизу**, как на дисплее камеры: выдержка, диафрагма, ISO, баланс белого, экспокоррекция, фокус. Клик по значению открывает меню Fn поверх кадра.
- **Меню Fn**: сетка 2×6, как на камере, — 11 настроек и вход во все остальные. Значения меняются кликом, стрелками или колесом мыши. Для баланса белого есть цветовая температура и площадка сдвига A–B / G–M.
- **«Все настройки»** по группам: экспозиция, фокус, цвет и картинка, видео, фото, камера.
- **Запись видео** кнопкой. Пока идёт запись, видна метка REC с таймером.
- **Фоторежим.** Переключатель «Фото / Видео» справа. Спуск с автофокусом. Снимки сохраняются на Mac (по умолчанию в «Загрузки»), на карту или туда и туда. При RAW+JPEG скачиваются оба файла.
- **Просмотр после съёмки**: снимок показывается 1–10 секунд, можно выключить. На выбор — скачанный файл или кадр с камеры.
- **Стоп-кадр из видео** кнопкой или клавишей S, запись при этом не прерывается.
- **Лента последних снимков**: клик открывает снимок поверх видео, правый клик — «Показать в Finder» или «Открыть».
- **Гистограмма** — отдельной кнопкой.
- **Пресеты**: сохранить текущие настройки и вернуть их одной кнопкой или цифрой 1–9.
- **Элементы управления прячутся** сами через 3 секунды без движения мыши или клавишей H.
- Без драйверов, sudo и сторонних библиотек: только системный ImageCaptureCore.

## Установка

Нужен Mac на Apple Silicon и macOS 14 или новее.

1. Скачайте `ZV-E10-Viewer.dmg` со страницы [Releases](https://github.com/Scryptor/SonyCamUsbOnMac/releases/latest).
2. Откройте его и перетащите «ZV-E10 Viewer» в «Программы».
3. Программа не подписана сертификатом разработчика Apple, поэтому при первом запуске macOS её не откроет. Чтобы открыть:
   - попробуйте запустить программу и закройте предупреждение;
   - откройте «Системные настройки» → «Конфиденциальность и безопасность», внизу нажмите «Всё равно открыть».

   Или одной командой в Терминале:

   ```bash
   xattr -dr com.apple.quarantine "/Applications/ZV-E10 Viewer.app"
   ```

При первом снимке в папку «Загрузки» macOS может спросить разрешение на доступ к ней: разрешите.

## Настройка камеры

Один раз на камере:

1. MENU → Network → Smartphone Connect → Smartphone Connection: **Off**
2. MENU → Network → PC Remote Function → PC Remote: **On**, PC Remote Cnct Method: **USB**

Потом подключите камеру к Mac кабелем USB-C. Через несколько секунд появится картинка.

Если камера подключена, но картинки нет: закройте Imaging Edge, «Захват изображений» и другие программы, которые могли занять камеру, и переподключите кабель.

Проверено на ZV-E10 с прошивкой 2.00. Другие камеры Sony с PC Remote по USB могут заработать, но не проверялись.

## Управление

| Клавиша | Что делает |
|---|---|
| F | открыть или закрыть меню Fn |
| ← → | изменить выбранную настройку в меню Fn |
| 1–9 | применить пресет |
| Пробел | снимок в фоторежиме; закрыть просмотр снимка |
| S | стоп-кадр в видеорежиме |
| H | скрыть или показать элементы управления |
| Esc | закрыть меню или просмотр |
| ⌘, | настройки программы |

Буквы работают и в русской раскладке (F/А, S/Ы, H/Р). Колесо мыши над меню Fn листает значения выбранной настройки.

Пресеты — вверху слева: «+» сохраняет текущие настройки, клик по пресету применяет его, правый клик — переименовать или удалить.

В настройках программы (⌘,) выбирается, куда сохранять снимки (на Mac и на карту, только на Mac, только на карту) и в какую папку, сколько секунд и что показывать после съёмки, прятать ли элементы управления.

## Ограничения

- Камера отдаёт по USB только превью: 1024×576 в видеорежиме, в фоторежиме зависит от соотношения сторон (при 1:1 — 1024×1024), около 20–24 кадров в секунду. Большего по USB добиться не удалось: свойство качества превью картинку не меняет. Видео лучшего качества дают режим камеры USB Streaming (камера становится веб-камерой) или захват по HDMI, но это уже без этой программы.
- Поэтому и стоп-кадр из видео — это кадр превью, 1024×576, а не полноразмерный снимок.
- Экспонометр (M.M.) в ручном режиме камера по USB не отдаёт, программа его не показывает.
- Во время записи видео нельзя снять фото и переключить режим.
- Зум на объективе механический: программа им не управляет.

## Сборка из исходников

Нужен Xcode 16 или новее (Swift 6).

```bash
swift test               # модульные тесты, камера не нужна
scripts/build-app.sh     # build/ZV-E10 Viewer.app
scripts/make-dmg.sh      # build/ZV-E10-Viewer.dmg
```

Устройство проекта:

- `Sources/ZVCore` — протокол PTP, команды Sony, сессия с камерой, настройки, пресеты, съёмка. Без интерфейса, покрыто тестами (`Tests/ZVCoreTests`, в том числе на дампах с настоящей камеры).
- `Sources/ZVCamera` — связь с камерой через ImageCaptureCore.
- `Sources/ZVViewer` — само приложение на SwiftUI.
- `Sources/zv-probe` — утилита командной строки для опытов с камерой: `info`, `props`, `lv`, `set`, `rec`.
- `Resources/AppIcon.icon` — иконка в формате Icon Composer. `scripts/make-icon.sh` пересобирает из неё `Assets.car` и `AppIcon.icns`, для этого нужен Xcode 26.
- `docs/superpowers` — описание проекта и план разработки.

### Как программа говорит с камерой

Всё идёт через `ICCameraDevice.requestSendPTPCommand(_:outData:completion:)` из ImageCaptureCore: это обычные PTP-команды плюс команды Sony. Что пришлось выяснить опытным путём:

| Что | Как |
|---|---|
| Данные команды | в `outData` передаётся только само значение, без заголовка контейнера PTP: заголовок ImageCaptureCore добавляет сам |
| Рукопожатие | GetDeviceInfo `0x1001` → `0x9201(1,0,0)` → `0x9201(2,0,0)` → `0x9202(0x12C,1)`, пока не вернёт данные → `0x9201(3,0,0)` |
| Управление с компьютера | свойство PriorityMode `0xD25A` = 1 через `0x9205`; без него, например, диафрагма только для чтения |
| Первые секунды | после рукопожатия камера около 3 секунд молча игнорирует запись настроек |
| Все свойства | `0x9209` возвращает список в формате Sony; запись одного значения — `0x9205`, применяется примерно за 0,6 с, после чего приходит событие `0xC203` |
| Превью | GetObject `0xFFFFC002`: в начале — смещение и размер JPEG |
| Кнопки | `0x9207`: 2 — нажать, 1 — отпустить. Запись `0xD2C8`, спуск наполовину `0xD2C1`, полностью `0xD2C2` |
| Снимок | готов, когда `0xD215` > `0x8000`; забирается через GetObjectInfo / GetObject `0xFFFFC001`, при RAW+JPEG — два объекта подряд |
| Куда сохранять снимки | `0xD222`: `0x01` — Mac, `0x10` — карта, `0x11` — оба |
| Фото или видео | режим `0x500E`: видеорежимы — `0x7xxxx` и `0x9xxxx`, например `0x78053` — видео M, а фото M — `0x1` |

### API для автоматических тестов

Если запустить программу с флагом `--automation`, она откроет локальный API на `127.0.0.1:47811`:

```bash
"/Applications/ZV-E10 Viewer.app/Contents/MacOS/ZVViewer" --automation
```

Порт и токен (заголовок `X-ZV-Token`) лежат в `~/Library/Application Support/ZV-E10 Viewer/automation.json`, файл доступен только текущему пользователю. Без флага API выключен.

- `GET /state` — состояние камеры и экрана в JSON;
- `POST /action` — действия: открыть меню, изменить настройку, сохранить пресет, снять, переключить режим и т. д.;
- `GET /screenshot` — PNG окна;
- `GET /frame` — последний кадр превью в JPEG.

`scripts/zvapi.py` делает один запрос. `scripts/e2e.py` и `scripts/e2e_photo.py` — сквозные тесты на настоящей камере: они меняют настройки и делают снимки (только на Mac, в указанную папку), а в конце возвращают всё как было.
