# Наложение кадра: панель, прозрачность, «спрятать», эталон из файла

2026-10-28. Продолжение функции 7 «Наложение» (v0.8.0): там эталон брался только из живого кадра или снимка из галереи,
а непрозрачность — тремя ступенями в меню «Монитор».

## Что просил пользователь

- брать эталон из файла картинки;
- менять прозрачность прямо в работе;
- щелчком прятать и показывать наложение, «типа плавающей кнопки».

## Решения

**Плавающая панель наложения** — как панели гистограммы и волновой формы: тащится, место запоминается, у края прилипает,
на правую колонку кнопок не ложится, на планшете поднимается над меню Fn и «Монитор». Видна, пока наложение включено и
эталон есть; не прячется вместе с элементами (как гистограмма), прячется под просмотром снимка и галереей. По умолчанию —
справа вверху, под строкой состояния.

На панели:
- **миниатюра эталона — кнопка «спрятать / показать»**: щелчок (касание) мгновенно убирает эталон с кадра и
  возвращает его — сравнение «было / стало» без анимации; спрятанный — миниатюра притушена, на ней перечёркнутый глаз;
- **ползунок непрозрачности** 5–100 % с шагом 5. 100 % вместе со «спрятать» — чистое мигание «эталон ↔ живое»;
- **«Новый кадр»**, **«Из файла…»** и **✕** — выключить наложение.

«Спрятать» — не настройка: после перезапуска, нового эталона или повторного включения эталон снова виден.

**Эталон из файла.** Mac — окно выбора файла (любой формат картинки, что понимает macOS: JPEG, PNG, HEIC, TIFF…) и
перетаскивание картинки на окно программы. Android — системный выбор файла (`ACTION_OPEN_DOCUMENT`, `image/*`): галерея,
«Загрузки», облако. Картинка уменьшается до 2048 точек по длинной стороне с учётом поворота из EXIF и сохраняется как
эталон (переживает перезапуск, исходный файл можно удалить); подпись — имя файла. Взяли эталон — наложение включается.

**Клавиша O** (Щ в русской раскладке) на Mac: наложение выключено — включить; включено — спрятать или показать.

**Модель.** `MonitorAssist.overlay` — не перечисление 25/50/75, а проценты 5–100 или «off»; в настройках и API — строкой,
как раньше, поэтому старые «25», «50», «75» читаются без изменений. Ступени в меню «Монитор»: Выкл, 25, 50, 75, 100 %;
значение с ползунка между ступенями показывается на плитке как есть («40 %»), стрелки идут к соседней ступени, повторное
касание плитки возвращает именно 40 %.

## API и проверки

Mac: `toggleOverlay` (как O), `referenceFromFile` с `path`, `moveOverlayPanel` (`x`, `y`), `setAssist overlay` — любые
проценты 5–100; в `/state` — `ui.overlay` (`hidden`, `position`). Android: `DEBUG_ASSIST --ez overlayToggle true`.
Сквозные проверки — в `scripts/e2e_monitor.py`.
